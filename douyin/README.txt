像素A3 — 抖音原生小游戏调试工程，版本 0.1.0
AppID: ttbf93c92e21efdb9f02

将本目录导入抖音开发者工具的“小游戏”，以 game.js 为入口。
代码由共享 TypeScript 规则引擎和原生 Canvas UI 构建，无网页或 WXML 依赖。

目前完成：本地构建、18项自动化测试、三种宽度的浏览器 tt 模拟触控验证。
待完成：官方模拟器和真机验证、合法请求域名及固定API上线配置、上传平台测试版。
离线机器人练习无需账号与服务器；好友房需要完成以上网络配置。

后台已保存应用基本资料草稿；用户没有软著证书，尚未提审或发布。
正式发布前需补齐软著审核、游戏备案、ICP备案及平台实际要求。

字体许可证见 assets/OFL.txt 和 assets/LICENSES。
重建：在项目根目录运行 npm run build:douyin。
