安装只需三步

已有正式版的玩家可直接覆盖升级。

  1. 01
    下载安装包

    点击下载按钮，等待 APK 下载完成。网络较慢时，也可打开 GitHub 发布页，在 Assets 中选择 shanshui-a3.apk。

  2. 02
    允许本次安装

    在浏览器下载列表中打开 APK。若系统提示来源权限，请按提示允许该浏览器“安装未知应用”。

  3. 03
    打开应用，开始牌局

    可先离线练习；登录后创建好友房。应用会通过固定入口查找当前服务器，电脑端服务需要保持运行。
