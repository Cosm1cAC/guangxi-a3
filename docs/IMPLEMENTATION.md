# 广西 A3 实现约定

来源：工作区《广西A3（尖3）棋牌规则.md》（2026-11-14 第10章修订）。

默认采用基础分制、每局 ♦4 首出、下家接风、同花最大牌优先、报单可压必打、过牌后允许再出。仅娱乐积分。多局累计；从第二局起按 §17 推荐规则进贡还贡（`createNextGame` / `returnTribute`），受贡者逐张手动选择非身份牌等量返还，可退原贡牌，不能返还 ♠A、♠3，不采用免贡／抗贡，所有人还完后按最终手牌确定阵营和 ♦4 首出。好友房「下一局」接口幂等，任一玩家触发。不启用叫独食倍数、摆牌、投降及地区变体。界面开局前明确展示。

2v2 全败局末游→头游、三游→二游各贡 2 张；半败局末游→头游、二游→三游各贡 1 张；1、4 名一队对 2、3 名一队为平局，双方 0 分、无贡牌。独食全胜／全败每家 2 张、半胜／半败每家 1 张，输方向赢方进贡；独食者输时按对方名次从前到后分配。贡牌为除 ♠A、♠3 外最大牌，自动扣交、仅双方可见。受贡者逐张手动选择非身份牌等量返还，可退原贡牌，不能返还 ♠A、♠3。不采用免贡／抗贡；全部还完后每人 13 张，由最终持有 ♦4 的玩家首出，首手必须包含 ♦4。

规则文档 6.5 / 7.2 的同花例子把 K 当作含 3、2 同花的最大牌，与 5.1 的总牌序冲突；实现依据明确的 5.1 总牌序（3 > 2 > A > K），顺子才使用自然序列。2v2 提前结算时未出完的同队成员按座位补名次，标注“补位”，不影响分数。

架构：共享纯 TypeScript 引擎；Web Vite + Three.js；原生小程序 WXML/WXSS + scoped Three.js；Node Express API；PostgreSQL JSONB 状态、行锁、版本号、对局记录。练习模式可离线运行，联机采用同一服务端裁判。Web 与小程序共享规则和场景构建函数，不共享 DOM。

视觉：山水茶室，石青 #173f48、湖绿 #397469、铜金 #d3b37b、米白 #eef0df、朱红 #b34c49。标题宋体，正文系统无衬线，数据等宽。核心视觉为铜鼓纹八方茶桌、远山与水面。牌面和装饰使用自制矢量/程序化几何，不依赖外部图片。

验收：八种牌型、状态推进与零和结算测试；机器人完整对局；API 隐私、非法动作与并发校验；Web 真浏览器流程与截图；小程序构建。微信真机需微信开发者工具及用户 AppID；发布还需 HTTPS API 域名。
