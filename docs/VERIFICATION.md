## 2026-11-14 免费固定入口与 Cloudflare 候选 IP 筛选

- 固定入口 `https://a3.vibelink.cloud/go/` 和域名首页现返回一次 302，目标从本机 `.local/cpolar/public.json` 动态读取，响应包含 `Cache-Control: no-store, max-age=0`。仅入口请求经 Cloudflare，游戏仍走 cpolar；无需新增付费服务或云服务器。
- `--cpolar` 同时启动游戏 3002、回环地址上的跳转服务 3003、cpolar 及 Cloudflare 入口连接。cpolar 输出中的新地址通过公网 HTTPS 健康检查后才发布，检测到重连新地址会自动更新；失败则保留旧目标并重试。无效域名、HTTP、含凭证／端口／路径的发布目标被拒绝。
- 实际重连两次，目标先从 `6aadc08e.r9.cpolar.cn` 自动变为 `1e833c2.r9.cpolar.cn`，再变为 `4cce6938.r9.cpolar.cn`。同一固定入口始终进入当前游戏；手机浏览器验证标题正确、无脚本错误，查询参数在跳转中保留。跳转后的浏览器地址栏仍显示 cpolar 域名，换域名后登录状态可能需重新建立。
- 测量20个官方 Tunnel IP，每个4次 TCP 7844 连接，从无连接失败且中位数≤350ms的候选中选最快4个。最终启动选用 198.41.200.53／198.41.200.113／198.41.192.47／198.41.200.43，握手中位数216–229ms，4条真实 HTTP/2 隧道注册成功；机房仍为 LAX。当前 cloudflared 2026.7.1 支持 `edge`，但官方源码标为内部测试参数，原配置已备份，可回退默认发现。

- 新增 `CF节点测速.cmd`；`穿透启动.cmd`、`公网启动.cmd` 均启动免费固定入口方案。原全流量 Cloudflare 配置备份在 `.local/cloudflared/config.pre-entry.yml`。未修改其他域名的隧道。
